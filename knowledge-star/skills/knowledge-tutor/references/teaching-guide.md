# 知识星图教学指南

## 教学原则

### 1. 主动但不打扰
- 只在任务明显涉及知识点时主动提示
- 提示要简洁，不要打断工作流
- 用户可以说「跳过」或「稍后」来关闭提示

### 2. 渐进式教学
- 第一次接触：显示摘要
- 第二次接触：显示详细内容
- 第三次接触：显示相关知识点和依赖

### 3. 实践导向
- 结合当前任务解释知识点
- 提供实际代码示例
- 强调「为什么」而不只是「是什么」

## 教学格式

### 简短提示（任务进行中）
```
📚 相关知识：【XXX】- 简短摘要
```

### 详细教学（用户请求时）
```
🎓 知识详解：【XXX】

📝 摘要：
xxx

📖 详细内容：
xxx

🔗 相关知识点：
- [相关1] - 简短描述
- [相关2] - 简短描述

📊 掌握度：⭐⭐⭐ (3/5)
📈 查看次数：15次

💡 学习建议：
xxx
```

### 学习路径推荐
```
🗺️ 推荐学习路径：

当前位置：【XXX】

下一步：
1. 【推荐】YYY - 原因
2. 【可选】ZZZ - 原因

跳过：输入「继续」
```

## 进度更新规则

### 自动更新
- 任务涉及知识点 → vc +1
- 用户查看详细内容 → vc +1

### 手动更新
- 用户说「学会了」→ mastery +1
- 用户说「掌握了」→ mastery +2
- 用户说「精通了」→ mastery 设置为 5

### 周报触发
- 每周日自动生成
- 用户说「生成周报」立即生成

## 特殊情况处理

### 1. 知识点冲突
如果任务涉及多个相关知识点，按以下优先级：
1. 掌握度最低的优先
2. 影响力最高的优先
3. 最近查看的优先

### 2. 前置依赖未完成
如果任务涉及的知识点有未完成的前置依赖：
```
⚠️ 注意：【XXX】有前置依赖未完成：
- [依赖1] - 掌握度: ⭐⭐
- [依赖2] - 掌握度: ⭐

建议先完成前置依赖，要我现在解释吗？
```

### 3. 知识点过时
如果知识点的最后查看时间超过30天：
```
🔄 提醒：【XXX】已经30天没复习了，建议回顾一下。
```

## 与其他 Agent 协作

### 知识同步
- 所有 Agent 共享同一个知识星图文件
- 任何 Agent 的更新都会反映到所有 Agent

### 避免重复教学
- 如果用户已经在其他 Agent 学过某个知识点，不要重复教学
- 可以通过查看 vc（查看次数）来判断
