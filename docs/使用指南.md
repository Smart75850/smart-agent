## 环境准备

### 系统要求

- Python 3.11+
- Windows / macOS / Linux
- Chrome 浏览器（仅首次收割会话时需要）

### 安装步骤

```bash
# 1. 克隆仓库
git clone https://github.com/Smart75850/smart-agent.git
cd smart-agent

# 2. 安装依赖
pip install -r requirements.txt

# 3. 安装浏览器驱动（CDP 兜底时需要）
playwright install chromium
```

### 依赖说明

| 依赖 | 用途 | 是否必须 |
|------|------|:--:|
| httpx | HTTP 请求 | ✅ 必须 |
| curl_cffi | 贴吧 TLS 指纹模拟 | ✅ 必须 |
| playwright | CDP 浏览器兜底 | 可选 |
| fastapi + uvicorn | WebUI 仪表板 | 可选 |
| openpyxl | Excel 输出 | 可选 |

## 快速上手

### 第一次使用

```bash
# 最简单的使用：B站搜索，无需任何配置
python main.py --platform bilibili --keyword "Python教程"
```

B站是唯一一个完全无需登录、无需收割会话、甚至不需要浏览器的平台（纯 Python Wbi 签名）。

### 全平台使用

要使用其他平台，需要先收割一次会话：

```bash
# 1. 打开已登录各平台的 Chrome 浏览器（CDP 调试模式）
# Windows:
chrome.exe --remote-debugging-port=9222

# macOS:
/Applications/Google\ Chrome.app/Contents/MacOS/Google\ Chrome --remote-debugging-port=9222

# Linux:
google-chrome --remote-debugging-port=9222

# 2. 收割全部平台会话
python -c "import asyncio; from src.utils.session_manager import harvest_all; asyncio.run(harvest_all())"

# 3. 收割完成后，即可关掉 Chrome，纯 HTTP 直连
python main.py --platform all --keyword "美食"
```

### CLI 命令格式

```bash
python main.py --platform <平台> --type <操作> --keyword <关键词> --limit <数量>
```

### 完整参数列表

| 参数 | 必填 | 默认值 | 说明 |
|------|:--:|------|------|
| `--platform` | ✅ | bilibili | 目标平台，可选: bilibili, xiaohongshu, douyin, zhihu, kuaishou, weibo, tieba, all |
| `--type` | ❌ | search | 操作类型: search, hot, detail, comment, user |
| `--keyword` | ❌ | "" | 搜索关键词（search 类型必填） |
| `--limit` | ❌ | 20 | 返回结果数量 |
| `--output` | ❌ | output/ | 输出目录 |
| `--dry-run` | ❌ | — | 预览执行计划，不实际爬取 |
| `--list-platforms` | ❌ | — | 列出所有支持的平台 |

## 会话管理

### 会话是什么？

会话是你在浏览器中登录各平台后产生的 cookies 和签名令牌。Smart Agent 从浏览器中一次性收割这些数据，保存为 JSON 文件，之后直接用于 HTTP API 请求，不再需要浏览器。

### 会话文件位置

```
browser_data/
├── douyin_http_session.json       # 抖音
├── xhs_http_session.json          # 小红书
├── ks_http_session.json           # 快手
├── zh_http_session.json           # 知乎
├── weibo_http_session.json        # 微博
├── tieba_http_session.json        # 贴吧
└── session_context.json           # 抖音（额外格式）
```

### 查看会话状态

```python
from src.utils.session_manager import list_platforms, session_info, check_health

# 列出所有平台
print(list_platforms())

# 查看某个平台的会话信息
info = session_info("weibo")
print(info)  # {'platform': 'weibo', 'exists': True, 'harvested_at': '...', 'cookies_len': 1313}

# 健康检测
import asyncio
healthy = asyncio.run(check_health("weibo"))
print(f"微博会话: {'正常' if healthy else '过期'}")
```

### 手动收割

```bash
# 收割全部平台
python -c "import asyncio; from src.utils.session_manager import harvest_all; asyncio.run(harvest_all())"

# 收割单个平台
python -c "import asyncio; from src.utils.weibo_http import harvest_from_cdp; asyncio.run(harvest_from_cdp())"
```

### 自动收割

从 v0.2 开始，适配器内置了自动收割机制。每次搜索前，系统会先检测会话是否有效：

1. 发一个最小 API 请求验证会话
2. 如果过期，自动从 CDP Chrome 重新收割
3. 如果 CDP Chrome 未运行，自动降级到浏览器 CDP 路径

无需手动干预。

### 会话有效期

| 平台 | 大概有效期 | 备注 |
|------|:--:|------|
| 抖音 | ~60 天 | sessionid 较长效 |
| 小红书 | 数天 | x-s 令牌有时效 |
| 知乎 | 数天~数周 | cookies 有时效 |
| 快手 | 数天 | cookies 有时效 |
| 微博 | 数小时~数天 | 需要较频繁刷新 |
| 贴吧 | 数天 | cookies + curl_cffi |
| B站 | 永久 | 纯 Python 签名，无需收割 |

## 各平台使用方法

### B站（bilibili）

```bash
# 搜索（无需登录，零浏览器）
python main.py --platform bilibili --keyword "Python教程" --limit 40

# 热门视频榜
python main.py --platform bilibili --type hot

# 视频评论
python main.py --platform bilibili --type comment --keyword "BV1xx411c7mD"
```

B站完全不需要浏览器和登录，使用纯 Python Wbi 签名（MD5 hashlib），即开即用。

### 小红书（xiaohongshu）

```bash
# 搜索笔记（需先收割会话）
python main.py --platform xiaohongshu --keyword "美食探店" --limit 20

# 笔记详情
python main.py --platform xiaohongshu --type detail --keyword "笔记ID"

# 笔记评论
python main.py --platform xiaohongshu --type comment --keyword "笔记ID"
```

小红书需要 cookies + x-s-common + x-s + x-t + x-b3-traceid。x-s 是会话级令牌，收割一次后可以跨关键词、跨页面复用。

### 抖音（douyin）

```bash
# 搜索视频（需先收割会话）
python main.py --platform douyin --keyword "编程教学" --limit 40

# 用户作品
python main.py --platform douyin --type user --keyword "用户ID"

# 视频评论
python main.py --platform douyin --type comment --keyword "视频ID"
```

抖音需要 sessionid + ttwid + uifid（会话上下文），a_bogus 签名不是必需的。收割后纯 HTTP 直连零浏览器。

### 知乎（zhihu）

```bash
# 搜索问答
python main.py --platform zhihu --keyword "人工智能" --limit 20

# 热榜
python main.py --platform zhihu --type hot

# 问题详情
python main.py --platform zhihu --type detail --keyword "问题ID"

# 问题评论
python main.py --platform zhihu --type comment --keyword "问题ID"
```

知乎只需 cookies，不需要 x-zse-96 签名。

### 快手（kuaishou）

```bash
# 搜索视频（需先收割会话）
python main.py --platform kuaishou --keyword "美食"

# 热榜
python main.py --platform kuaishou --type hot
```

快手最简单：只需要 cookies，连签名都不需要。

### 微博（weibo）

```bash
# 搜索微博（需先收割会话）

# 热搜榜
```


## 纯 HTTP 模式详解

### 架构原理

Smart Agent 采用双路径容错架构：

```
搜索请求
  │
  ├── Path 1: 纯 HTTP Session
  │   ├── 加载收割的会话 (cookies + 签名令牌)
  │   ├── 直接调用平台搜索 API
  │   └── 成功 → 返回结果 (毫秒级)
  │
  └── Path 2: CDP 浏览器 (兜底)
      ├── 打开 Playwright 浏览器
      ├── DOM 提取 / API 拦截
      └── 返回结果 (秒级)
```

### 为什么纯 HTTP 更好？

| 对比维度 | 纯 HTTP | 浏览器 CDP |
|----------|---------|-----------|
| 响应速度 | 毫秒级 | 秒级 |
| 内存占用 | ~50MB | ~500MB+ |
| CPU 占用 | 极低 | 较高 |
| 并发能力 | 高（纯网络 IO） | 低（浏览器资源大户） |
| 稳定性 | 高（纯网络请求） | 中（浏览器可能崩溃） |
| 维护成本 | 低（收割一次用很久） | 低（兜底保障） |

### 会话收割原理

```
CDP Chrome (登录状态)
  │
  ├── playwright.connect_over_cdp()
  │     连接已登录的 Chrome 实例
  │
  ├── 提取 cookies (domain 过滤)
  │     只保留平台相关的 cookies
  │
  ├── API 拦截 (可选)
  │     捕获 x-s、x-zse-96 等签名头
  │
  └── 保存到 browser_data/*.json
        后续纯 HTTP 请求直接加载
```

## 代理池配置

### 配置文件

编辑 `config/proxies.json`：

```json
{
    "proxies": [
        "http://192.168.1.100:8080",
        "http://user:password@proxy.example.com:3128",
        "socks5://127.0.0.1:1080",
        "https://proxy.company.com:8443"
    ]
}
```

### 代理格式

| 协议 | 格式 | 示例 |
|------|------|------|
| HTTP | `http://[user:pass@]host:port` | `http://10.0.0.1:8080` |
| HTTPS | `https://[user:pass@]host:port` | `https://proxy.com:8443` |
| SOCKS5 | `socks5://[user:pass@]host:port` | `socks5://127.0.0.1:1080` |

### 代理池功能

- **自动轮转** — 每次请求使用不同的代理
- **健康检测** — 定期检查代理是否可达
- **失败剔除** — 连续失败 3 次的代理自动暂停
- **无代理时直连** — 代理池为空时自动使用直连模式

### 代理池 API

```python
from src.utils.proxy_pool import proxy_pool

# 查看状态
print(proxy_pool.status())

# 获取下一个代理
proxy = proxy_pool.get_next()
print(proxy.url)

# 手动添加
proxy_pool.add("http://new-proxy.com:8080")

# 手动移除
proxy_pool.remove("http://bad-proxy.com:8080")

# 健康检测全部代理
import asyncio
result = asyncio.run(proxy_pool.check_all())
```

## 存储后端

### 支持格式

| 后端 | 设置方式 | 说明 |
|------|------|------|
| JSON | `set STORE_BACKEND=json` (默认) | 结构化 JSON 文件 |
| CSV | `set STORE_BACKEND=csv` | Excel 可直接打开 |
| JSONL | `set STORE_BACKEND=jsonl` | 每行一个 JSON，适合大数据 |
| Excel | `set STORE_BACKEND=excel` | .xlsx 格式 |
| SQLite | `set STORE_BACKEND=sqlite` | 本地数据库 |
| MySQL | `set STORE_BACKEND=mysql` | 远程数据库（需配置） |

### 设置方法

**Windows (cmd)：**
```cmd
set STORE_BACKEND=csv
python main.py --platform all --keyword "美食"
```

**Windows (PowerShell)：**
```powershell
$env:STORE_BACKEND = "csv"
python main.py --platform all --keyword "美食"
```

**macOS / Linux：**
```bash
export STORE_BACKEND=csv
python main.py --platform all --keyword "美食"
```

### 输出目录

默认输出到 `output/` 目录，可通过 `--output` 参数修改：

```bash
python main.py --platform bilibili --keyword "Python" --output ./my_results
```

## 常见问题

### Q: 收割会话时报错 "CDP Chrome 未运行"

**A:** 需要先以 CDP 调试模式打开 Chrome：

```bash
chrome.exe --remote-debugging-port=9222
```

确保 Chrome 中已登录目标平台（抖音、小红书、知乎等）。

### Q: 知乎搜索返回空结果

**A:** 知乎需要登录才能获取完整搜索结果。在 CDP Chrome 中登录知乎后再收割会话。

### Q: 贴吧搜索失败

**A:** 贴吧使用 curl_cffi 模拟 TLS 指纹，确保 `pip install curl_cffi` 已安装。

### Q: 小红书搜索报错

**A:** 小红书需要完整的 cookies + x-s-common + x-s + x-t 签名。如果收割时浏览器未登录小红书，或登录已过期，需要重新登录后再收割。

### Q: 如何不依赖浏览器使用全部平台？

**A:** 完整流程：
1. 打开 CDP Chrome（已登录全部平台）
2. 运行 `harvest_all()` 收割全部会话
3. 关闭 Chrome
4. 之后全部使用纯 HTTP 模式，零浏览器

### Q: 会话能保存多久？

**A:** 取决于各平台。抖音最长（~60天），微博最短（可能数小时）。建议每天收割一次确保稳定。

### Q: 代理池何时生效？

**A:** 当 `config/proxies.json` 中有有效代理时，Session Manager 的健康检测和适配器搜索都会自动使用代理。

## 进阶技巧

### 单平台收割

```python
import asyncio
from src.utils.weibo_http import harvest_from_cdp

# 收割微博会话
sess = asyncio.run(harvest_from_cdp(port=9222))
print(f"收割成功: {sess.is_valid()}")
```

### 使用适配器 API

```python
import asyncio, json
from src.agents.weibo_adapter import WeiboAdapter

adapter = WeiboAdapter()

# 搜索
items = asyncio.run(adapter.search("人工智能", limit=10))
print(json.dumps(items, ensure_ascii=False, indent=2))

# 热榜
hot = asyncio.run(adapter.hot(limit=5))
print(json.dumps(hot, ensure_ascii=False, indent=2))
```

### 批量压测

```bash
python -c "
import asyncio, sys
sys.path.insert(0, '.')
from src.utils.session_manager import check_health, list_platforms

async def main():
    for p in list_platforms():
        h = await check_health(p)
        print(f'{p}: {\"OK\" if h else \"FAIL\"}')

asyncio.run(main())
"
```

### 集成到自己的项目

```python
import asyncio
from src.utils.zh_http import search_all

async def my_search():
    # 知乎纯 HTTP 搜索，零浏览器
    results = await search_all("人工智能", limit=20)
    for item in results:
        print(f"{item['title']} — {item['votes']}赞")

asyncio.run(my_search())
```

### 定时收割（推荐配置）

```python
# 每天自动收割一次，确保会话始终有效
import asyncio
from src.utils.session_manager import harvest_all

asyncio.run(harvest_all())
```

可以配合系统定时任务（Windows Task Scheduler / Linux cron）每天执行。
